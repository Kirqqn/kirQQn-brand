# kirQQn — конструктор превʼю (Python)

Той самий макет, що у веб-конструкторі kirQQn, але як скрипт. Усі розміри, відступи, шрифти й кольори зашиті в коді, тому кожне превʼю виходить ідентичним: змінюються тільки скрін, текст, номер і емоція QQ. Перевірено: результат збігається з веб-конструктором майже попіксельно (середня різниця менше 3 з 255 на піксель).

## Що в папці

| Файл | Що це |
|---|---|
| `kirqqn_thumb.py` | Сам конструктор |
| `series.json` | Підпис серії, акцент і бік тексту за замовчуванням. Міняєш один раз на нову гру |
| `fonts/` | Unbounded Black і JetBrains Mono Bold + ліцензії OFL |
| `assets/qq_*.png` | Сім емоцій QQ |
| `examples/` | Приклад фону і приклад пакетного файлу |
| `GPT_INSTRUCTIONS.md` | Інструкція для ChatGPT |

## Запуск у ChatGPT
Див. `GPT_INSTRUCTIONS.md`: вставиш текст в інструкції GPT, завантажиш архів — і GPT запускатиме скрипт замість того, щоб малювати.

## Запуск на своєму комп'ютері (Windows)
1. Встанови Python 3 з python.org (на першому екрані постав галочку «Add Python to PATH»).
2. У терміналі один раз: `pip install pillow`
3. У папці `kirqqn_thumb`:
```
python kirqqn_thumb.py --image D:\скріни\ksante.png --line1 "ДО БИТВИ" --line2 "З КСАНТЕ" --hl "КСАНТЕ" --badge "#14" --emotion look --out dawnwalker_14.jpg
```

## Параметри

| Параметр | Значення |
|---|---|
| `--image` | Скрін з гри, PNG або JPG. Будь-який розмір — скрипт сам заповнить кадр |
| `--line1`, `--line2` | Заголовок, разом 3–4 слова |
| `--hl` | Слово з заголовка для кольорової плашки |
| `--badge` | `#14`, `СКАРБИ` тощо |
| `--emotion` | `cry`, `look`, `shock`, `win`, `rage`, `dead`, `sleep` або `none` |
| `--accent` | `lime` (за замовчуванням) або `pink` |
| `--side` | `left` (текст зліва, за замовчуванням) або `right` |
| `--zoom`, `--ox`, `--oy` | Збільшити й зсунути скрін, якщо текст закриває головне |
| `--label` | Підпис біля бейджа; без нього береться з `series.json` |
| `--batch` | Пакетний режим: json-список превʼю (див. `examples/episodes.json`) |
| `--out` | Файл результату: `.jpg` (до 2 МБ, як вимагає YouTube) або `.png` |
