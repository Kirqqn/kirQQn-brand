# Комплект для самостійного монтажу

Спільні ресурси kirQQn, без записів гри, готових випусків і приватних проєктних нотаток.

## Зібрати папку
Після оновлення репозиторію запусти з його кореня:
```sh
python scripts/build_editing_kit.py --output "D:/EditingKit/kirQQn"
```
Обери нову папку поза репозиторієм. Скрипт нічого не видаляє та не перезаписує чинну папку; копіює ресурси, перевіряє SHA-256, записує MANIFEST.json з commit і відносними джерелами. Копія не оновлюється сама.

## Що імпортувати в Resolve
- 01_Intro: коротке інтро 3.6 с після привітання, не перед гачком.
- 02_Outro: перемога, 12 с, актуальний український CTA. Актуального аутро поразки поки немає.
- 03_Sounds: CC0-кряк для цензури та його ліцензія.
- 04_Overlays: переходи, ефекти, емоції, QQ 01–30, готові CTA коротких. Окремі бренд-звуки sfx_*.wav лежать тут і в episode/.
- 05_Logos, 06_Fonts: оригінальні знаки й шрифти з ліцензіями.
- 07_Constructors: конструктори, перед запуском читати їхні GPT_INSTRUCTIONS.md; 08_Templates: пресети Resolve; 09_Guidelines і 10_Brandbook: правила.

MOV з прозорістю клади над грою. За чорного фону перевір Clip Attributes → Alpha Mode → Premultiplied. Оверлеї можуть уже мати звук: не дублюй його однойменним WAV. Вбудований звук інтро/аутро не перезводь.
Glitch — для великого стрибка часу/місця; guide_step_wipe — між кроками гайду; skip_hud — над скороченням. Прямі склейки залишаються основою монтажу. До 3 емоцій і 2 мем-штампів на довгий випуск, між штампами ≥5 хв.

Лайку прибирати тільки з голосової доріжки й закривати кряком/біпом, гру зберігати. Переслухати межі. Лічильники QQ позиціонувати поза HUD; у коротких — тільки коли кількість фейлів працює як жарт.

Короткі: без інтро/аутро, один готовий CTA reaction/guide за ГАЙДЛАЙН_CTA_КОРОТКИХ.md. Мова за аудиторією. Для гайдів — брендінг конструктора без додаткового салатового handle.

Повні випуски: 2560×1440/60, H.264 High 24 Мбіт/с, keyframes 30, AAC 48 kHz 320+ Кбіт/с. Вертикальні: 1080×1920/60, 12 Мбіт/с. Ціль звуку −14 LUFS, true peak ≤−1 dBTP. Перевір готовий експорт, склейки, цензуру, CTA. Видача: відео, обкладинка з конструктора, опис.

Канонічні докладні правила — AI_INSTRUCTIONS.md та гайдлайни. Існуючі оригінальні медіафайли не змінено. Нове аутро ~33 MB зберігається за чинною схемою репозиторію (звичайний Git); міграцію історії на LFS не виконано.
