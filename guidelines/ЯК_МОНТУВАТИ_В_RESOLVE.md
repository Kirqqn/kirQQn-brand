# kirQQn — монтаж у DaVinci Resolve

Бренд у монтажі — це п'ять повторюваних елементів, а не ефекти. На бренд в одному епізоді має йти не більше 10 хвилин. Усе, що довше, з'їдає бюджет 5–10 годин на тиждень і глядачі цього не помітять.

## Що лежить у цій папці

| Файл | Що це | Де ставити |
|---|---|---|
| `qq_pop_cry / look / shock / win / rage / dead / sleep.mov` | Емоція QQ вискакує в правому нижньому куті й зникає, 1,5 с, зі звуком | Доріжка V2, над моментом |
| `plus_one_qq.mov` | «+1 qq» зі сльозою, 1,2 с, зі звуком | V2, на кожен фейл |
| `skip_hud.mov` | Плашка «▶▶ ПЕРЕМОТКА» у лівому верхньому куті, 1,8 с | V2, над склейкою, де вирізано мертвий шматок |
| `glitch_stinger.mov` | Глітч-перехід, 0,5 с | V2, серединою на склейці — тільки для великих стрибків |
| `handle_bug_vertical.png` | Знак QQ + @kirqqn для вертикалок, уже в безпечній зоні TikTok / Shorts | Верхня доріжка вертикалки, на весь кліп |
| `handle_bug_16x9.png` | Маленький знак у кутку для горизонтального відео | Не використовувати в епізодах — див. «Водяний знак» |
| `sfx_*.wav` | Ті самі звуки окремо | A3, якщо треба звук без картинки |

Усі `.mov` — ProRes 4444 з прозорим фоном, 2560×1440, 60 к/с, тобто в роздільності твого запису з OBS. `handle_bug_vertical.png` — 1080×1920. Resolve читає прозорість сам. Якщо замість прозорості бачиш чорний фон: правий клік на кліпі в Media Pool → Clip Attributes → Video → Alpha Mode → Premultiplied.

Інтро й аутро лежать у `D:\LetsPlay\brand`: `intro\kirQQn_intro_short_1080p60.mp4`, `kirQQn_outro_win_1080p60.mp4`, `kirQQn_outro_lose_1080p60.mp4`. Вони в 1080p — Resolve сам розтягне їх на таймлайн 1440p, нічого налаштовувати не треба.

## Разове налаштування — один вечір, ~1–1,5 год

1. **Шрифти.** Відкрий `kirQQn_kit_3_fonts_licenses_sound\fonts`. На кожному `.ttf`: правий клік → «Встановити для всіх користувачів». Перезапусти Resolve, інакше він шрифтів не побачить.
2. **Один проєкт на гру.** Наприклад «Dawnwalker». Усі епізоди цієї гри — окремі таймлайни в одному проєкті. Налаштування проєкту: **2560×1440, 60 к/с — як пише OBS.** File → Project Settings → Master Settings → Timeline Resolution → 2560×1440 → Save. Роздільність таймлайну має дорівнювати роздільності запису: якщо таймлайн менший, Resolve спершу стискає гру до 1080p, і деталі втрачаються ще до YouTube.
3. **Імпорт бренду.** У Media Pool створи бін `kirQQn` і перетягни туди всю цю папку, коротке інтро й обидва аутро.
4. **Таймлайн-шаблон `_ШАБЛОН`.** Доріжки:
   - V1 — Гра (сюди ж інтро й аутро, як звичайні кліпи)
   - V2 — Бренд (стікери, +1 qq, перемотка, глітч)
   - A1 — Гра, A2 — Голос, A3 — Бренд/SFX

   Поклади в шаблон: інтро після перших 15 секунд, обидва аутро в кінці (одне потім видалиш), по одному прикладу кожного оверлею збоку. Для нового епізоду: правий клік на `_ШАБЛОН` у Media Pool → Duplicate Timeline.
5. **Пресет рендеру «kirQQn YouTube».** Звірено з [рекомендаціями YouTube для завантаження](https://support.google.com/youtube/answer/1722171), Resolve 21.1. Deliver → Custom Export:

   | Поле | Значення | Чому |
   |---|---|---|
   | Format | MP4 | Контейнер, який радить YouTube |
   | Codec | H.264 | YouTube радить саме його. H.265 приймає, але все одно перекодовує |
   | Encoder | NVIDIA, якщо є в списку; інакше Native | NVIDIA рендерить швидше. Native теж годиться, просто довше |
   | Network Optimization | Увімкнено | Індекс файлу на початку (Fast Start) — вимога YouTube |
   | Resolution | 2560×1440 | За спостереженнями авторів, від 1440p YouTube стискає кращим кодеком — чіткіше навіть у 1080p |
   | Frame rate | 60 | Та сама частота, з якою записано |
   | Quality | Restrict to 24 000 Kb/s | Рекомендація YouTube для 1440p60. Ліміту нема: при швидкій заливці можна 40 000 для темних ігор |
   | Encoding Profile | High | Вимога YouTube для H.264 |
   | Key Frames | Every 30 frames | YouTube: група кадрів — половина частоти кадрів |
   | Frame reordering | Увімкнено | Вмикає B-кадри, YouTube радить 2 підряд |
   | Advanced → Data Levels | Auto | Інакше картинка може вийти блідою або з «провалленим» чорним |
   | Advanced → Color Space / Gamma Tag | Same as Project (Rec.709) | YouTube радить BT.709 для звичайного SDR |
   | Audio | AAC, найбільший бітрейт у списку (320+), 48 000 Hz, стерео | YouTube радить 48 кГц і 384 Kb/s для стерео |

   Якщо якогось поля у твоєму енкодері нема — лиши за замовчуванням. Меню «…» біля назви пресету → Save as New Preset → «kirQQn YouTube».

   **Перевірка після заливки:** правий клік по відео → Stats for nerds → рядок Codecs: `vp09` або `av01` — добре, `avc1` — гірше. Якщо картинка на YouTube блідіша, ніж у Resolve, винні теги кольору.
6. **Пресет «kirQQn Vertical»** — те саме, але 1080×1920 і Restrict to 12 000 Kb/s (рекомендація YouTube для 1080p60).

## Епізод: порядок бренд-елементів

1. **Захід (0:00–0:15).** Голосом: «Це kirQQn. Сьогодні ми ламаємо <гра>.» На тлі гри, без тексту.
2. **Коротке інтро (3,6 с)** — одразу після фрази, на V1 як звичайний кліп. Не першою секундою відео.
3. **Тіло — тільки прямі склейки.**
   - Вирізав мертвий шматок (біганина, завантаження, меню) → `skip_hud` на V2, початком на склейці.
   - Великий стрибок (наступний день, нова локація, інша сесія) → `glitch_stinger` серединою на склейці.
   - Стандартних переходів Resolve (Cross Dissolve, Slide, Zoom) не використовувати: вони не з бренду і повільніші.
4. **Емоції QQ — до трьох на епізод,** на найсильніших моментах:

   | Момент | Файл |
   |---|---|
   | Фейл, смерть, «ну як так» | `qq_pop_cry` |
   | Скример, раптова смерть, поворот | `qq_pop_shock` |
   | Клатч, скарб, бос з першої спроби | `qq_pop_win` |
   | Нечесний бос, баг, «ще раз?!» | `qq_pop_rage` |
   | Повний розгром | `qq_pop_dead` |
   | Щось помітив, «дивіться сюди» | `qq_pop_look` |
   | Пауза, AFK, нудне завантаження | `qq_pop_sleep` |

   Якщо в правому нижньому куті HUD гри: Inspector → Transform → Position, посунь стікер.
5. **`plus_one_qq` — на кожен фейл.** Рахуй їх: число йде у вихід.
6. **Вихід голосом:** «<Гра> — зламана.» або «<Гра> зламала мене.» Опційно: «Ціна: сім qq.»
7. **Аутро (12 с):** `outro_win`, якщо гру зламано, `outro_lose`, якщо гра зламала тебе. Останні 12 секунд відео. У YouTube Studio: відео 1 тягни вгору до упору, відео 2 і підписку — вниз до упору.

## Гайди (вертикальні, 1080×1920)

Повні правила — у `ГАЙДЛАЙН_ГАЙДИ.md` поруч. Картки робить конструктор «Гайди kirQQn» або `kirqqn_guide.py` з архіву `D:\LetsPlay\brand\kirqqn_guide.zip`. Вручну картки не малювати.

1. Таймлайн 1080×1920, 60 к/с — окремий, не з `_ШАБЛОН`.
2. **V1** — геймплей кроку. Inspector → Transform: Zoom **1.087**, Position Y **+180**. Обкладинка-плакат: Zoom **3.161**, Position Y **0**, Position X — на обличчя чи нагороду; темний кадр — Color → Gain +0.2. Картка «Далі»: Zoom **1.0**, Position Y **0**.
3. **V2** — PNG з `resolve_overlay` на всю довжину картки.
4. **V3** — `guide_step_wipe.mov` серединою на склейці між картками. Звук уже всередині; окремо — `sfx_guide_wipe.wav`.
5. Тривалість кроку: 1 с + 0,4 с на кожне слово на картці, не менше 2,5 с. Обкладинка 1–1,2 с — і саме її кадр обирай обкладинкою Short у застосунку YouTube. «Далі» 2 с.
6. Гайд довший за 8 кроків — ділиться на частини PT 1, PT 2… Кожна частина — окреме відео, нумерація кроків наскрізна.

## Текст на екрані (виправлено 4 жовтня 2026)

Раніше тут стояло «службовий підпис — лівий нижній кут». Це було хибно: у Dawnwalker там шкала здоров'я, і підпис лягав просто на HUD. Тепер титри, підписи, поради й переклади робляться тільки картками з конструктора «Титри kirQQn» або `kirqqn_episode.py` (архів `D:\LetsPlay\brand\kirqqn_episode.zip`) — кожна на своєму місці поза HUD. Повні правила — `ГАЙДЛАЙН_ЕПІЗОДИ.md` поруч.

- **В міру:** одна картка на екрані, не більше 2 за хвилину й 8 за 10 хвилин, нічого в перші 15 секунд.
- **Переклад ключових реплік** — головна картка формату. До 6 на епізод, над субтитрами гри.
- **Субтитрів власного голосу в довгих епізодах не робити.** Автосубтитри в Resolve є тільки в платній Studio, а вручну це години на епізод.
- Рух і меми — папка `episode`: `ep_card_in` / `ep_card_out`, `ep_stinger`, `ep_callout`, `ep_punch`, `ep_freeze`, шість мем-штампів `stamp_*`. Мемів до 2 на епізод і не частіше ніж раз на 5 хвилин.
- `qq_pop_*.mov` у Dawnwalker: Inspector → Position Y +360, бо правий нижній кут зайнятий предметами.

## Вертикалки (Shorts, TikTok, Reels)

- **Без інтро й аутро.** Перші три секунди — сама подія.
- **Гачок-текст зверху:** Unbounded Black, великими, не вище 130 px від верхнього краю і не правіше ~900 px (справа кнопки TikTok) і не ближче ~96 px до лівого краю (на високих телефонах стрічка обрізає боки). `handle_bug_vertical.png` з 18 жовтня стоїть на x 96.
- **`handle_bug_vertical.png`** — на верхню доріжку на весь кліп. Він уже стоїть над зоною підпису й лівіше кнопок.
- **Одна емоція QQ** на кульмінацію — можна, більше не треба.
- **Текст мінімальний.** Один файл іде на всі три платформи, тож якщо текст є — англійською (Instagram і TikTok у тебе англійською).

## Звук

- Голос — головне; гра не повинна його перекривати.
- Бренд-оверлеї мають звук усередині `.mov`. Якщо заголосно — гучність кліпу −6 dB в Inspector.
- **Перед рендером:** Fairlight → Loudness Meter, програй таймлайн. Ціль для YouTube: −14 LUFS integrated, true peak не вище −1 dBTP. Підтягни фейдер Main, якщо треба. Інтро й аутро вже зведені, їх не чіпай.

## Водяний знак

У сам епізод знак не вшивати. YouTube має власний: Studio → Персоналізація (Customization) → Брендинг → Водяний знак відео → `youtube_video_watermark_300.png` з `04_youtube`. Він клікабельний (кнопка підписки) і з'являється на всіх відео автоматично, без роботи над кожним.

## Чого не робити

- Стандартні переходи, «зум на кожну репліку», тряска камери.
- Музика з інтернету: Content ID. Увесь звук бренду синтезований і безпечний.
- Більше трьох стікерів на епізод — бренд перетворюється на шум.
- Текст на пів екрана в довгих епізодах.
