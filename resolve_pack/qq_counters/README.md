# Лічильники QQ 01–30

Наявні брендовані PNG з монтажного комплекту, 2560×1440, RGBA. Статичне число без слова TOTAL. Нульова картка в цей набір не входить.
Використовувати на доріжці над грою: після підтвердженої смерті замінити число, не рахувати повтор того самого моменту в гачку.
Знак у вихідному PNG знизу ліворуч; у Resolve розмістити відносно HUD конкретної гри, не перекривати інтерфейс. Сам PNG не означає готове позиціонування для будь-якої гри.
Для довгих випусків — постійний лічильник за вказівкою автора. Для коротких — лише якщо кількість смертей є фокусом жарту.
